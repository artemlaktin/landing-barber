---
name: task
description: Составить понятное описание задачи для разработчика — когда просьба сложная (оплата, формы, новая страница, интеграция, редизайн) и её нельзя сделать самим. Используй, когда человек пишет /task или соглашается передать задачу разработчику.
---

1. Расспроси человека (по одному короткому вопросу, не больше 3–4 вопросов всего), если чего-то не хватает:
   что нужно, зачем (какую проблему решает), где на сайте, есть ли пример (ссылка на другой сайт, скриншот), срочность.
2. Посмотри код, чтобы указать разработчику, какие файлы скорее всего затронуты.
3. Составь текст задачи по-русски:

   ```
   ## <Короткое название>
   **Что нужно:** …
   **Зачем:** …
   **Где на сайте:** …
   **Пример / референс:** …
   **Срочность:** …
   ---
   Для разработчика: вероятно затронуто — <файлы>. <Технические заметки, если есть>.
   ```

4. Покажи текст человеку и скажи: «Скопируйте и отправьте разработчику». Ничего в коде не меняй.
