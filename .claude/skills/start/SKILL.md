name: start
description: Запустить сайт локально на компьютере и открыть его в браузере, предварительно подтянув свежую версию. Используй, когда человек хочет посмотреть сайт у себя или начинает работу.
---

1. Свежая версия: `git branch --show-current` и `git status --short`.
   - Если в `main` и нет несохранённых изменений — `git pull --ff-only`.
   - Если в ветке `edit/...` и `git fetch` + `git branch -r --merged origin/main` показывает, что ветка уже принята
     разработчиком — переключись: `git switch main && git pull --ff-only`, и скажи, что начинаем с новой версии.
   - Иначе ничего не трогай.
2. Проверь, не запущен ли уже сервер: `curl -s -o /dev/null -w "%{http_code}" http://localhost:3000/pl`.
3. Если не запущен — запусти `npm run dev` в фоне (run_in_background) и подожди, пока `/pl` начнёт отвечать 200.
   Если в папке нет `node_modules` — сначала `npm install` (предупреди, что это займёт пару минут).
4. Открой http://localhost:3000/pl в браузере (chrome-devtools `new_page`), если браузер доступен.
5. Скажи человеку простыми словами: «Сайт запущен у вас на компьютере: http://localhost:3000/pl.
   Это только ваша копия — посетители её не видят. Изменения будут появляться на ней сами».
   Если человек тут впервые — предложи `/howto`.
